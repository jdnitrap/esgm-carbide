Definition

Mechanically Defined Byte-Level Embedding (MDBE): An input
representation matrix for language models where the rows are
permanently mapped to raw character byte values (such as hexadecimal
UTF-8 bytes) and the columns represent explicitly hardcoded, human-
interpretable linguistic and grammatical constraints. The cell values are
fluid, floating-point decimals that quantify the alignment of each
individual character byte with those specific structural rules.
